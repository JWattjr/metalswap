# Ready-to-paste Portal description

MetalSwap is a focused GenLayer StudioNet prototype for one bounded question: over a 15-minute UTC interval, does Gold or Silver deliver the stronger relative return? It keeps one pair and demo-credit pari-mutuel mechanics. The current deployment freezes XAUS's public XAU/USD and XAG/USD intraday series as a named indicative historical-replay source; the preserved synthetic market demonstrates the complete payout lifecycle.

Validators verify frozen source identity, successful bounded HTTP/UTF-8/JSON transport, exact instruments and units, fresh ordered observations, boundary selection, staleness/skew limits, canonical hash agreement, deterministic integer cross multiplication, refund/pool/fee/payout conservation, authenticated finality gating, idempotent retry, pagination, cutoff enforcement, and duplicate-claim rejection. Arithmetic is contract code; no LLM adjudicates numbers. Direct regression tests use mocked HTTP responses. The deployment/binding/readback receipts are live; the complete expiry-to-payout flow was demonstrated live only with the explicitly synthetic source.

Synthetic outcomes are public, developer-generated, deterministic, and predictable; delaying publication does not make them unpredictable. Demo credits have no cash value. MetalSwap is a controlled mechanics prototype plus a historical source comparison, not real-price trading, executable pricing, custody, leverage, AMM, or order-book infrastructure. Real-price demonstration readiness is not claimed because the verified XAUS feed is indicative/non-executable and was unavailable on a later probe.
